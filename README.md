# KnowledgeBase1C

Внутреннее приложение для учета и систематизации ошибок конфигураций 1С. Сделано в рамках практики в ООО «СтавАналит».

## Стек

* C# (.NET 8 / Windows Forms)
* SQLite (хранение данных)
* BCrypt (хеширование паролей)

## Как запустить

Для работы должен быть установлен .NET Runtime
Также приложении из-за безопасности Windows должно быть установлено на другой диск или переместить папку приложения на рабочий стол

## Тестовые аккаунты

Логин  Пароль  Роль

smirnov 123 Специалист 1С (полный доступ)

## Что внутри

* `Forms/` — код интерфейса (вход, главное окно, форма редактирования).
* `Data/Database.cs` — вся работа с SQLite, там же инициализация и создание дефолтных записей.
* `Models/` — классы данных.
* `schema.sql` — sql-файл со структурой (в коде он не используется, оставил для наглядности).
